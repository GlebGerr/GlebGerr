## Ключевые проекты

### AI-генерация тестов для Moodle

Разработал приложение на **Python + LLM API**, которое:

- автоматически генерирует тестовые вопросы
- формирует пул заданий
- создает адаптивные тесты

Результат:
- значительное сокращение времени подготовки учебных материалов.

---

### AI-анализ результатов обучения

Создан инструмент, который:

- анализирует результаты тестирования
- выявляет пробелы в знаниях
- формирует персональные рекомендации

Реализован **RAG-поиск** по базе материалов:
- курсы
- статьи
- внутренние документы
